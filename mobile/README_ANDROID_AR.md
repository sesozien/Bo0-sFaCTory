# Bo0 Factory Android APK

تم تجهيز نسخة Android خفيفة بواجهة عربية مناسبة للهاتف. الواجهة الحالية تحتوي على الكتالوج المحلي، إضافة المنتجات بالصور، منع التكرار، اعتماد المنتجات، القص بالإحداثيات مع معاينة وخطوط إرشادية، حفظ PNG غير فاقد للجودة، وتصدير PDF ومشاركته.

## تجربة الواجهة الآن

من داخل مجلد `mobile`:

```bash
npm install
npx expo start
```

يمكن فتحها على هاتف Android من خلال Expo Go بعد مسح QR، أو تشغيل المعاينة على الويب للاختبار.

## بناء APK تجريبي

يتطلب بناء ملف APK فعلي تسجيل الدخول إلى حساب Expo/EAS مرة واحدة:

```bash
npx eas-cli login
npx eas-cli build --platform android --profile preview
```

أو شغّل `build_apk.bat` على Windows أو `build_apk.sh` على Linux/macOS. ملف `eas.json` مضبوط ليطلب APK قابلًا للتثبيت، وليس AAB.

بيئة Sandbox هنا نجحت في تجميع حزمة Android JavaScript والتحقق من TypeScript، لكنها لا تحتوي على Android SDK أو حساب Expo لتسليم APK فعليًا من داخلها. بعد تسجيل الدخول، EAS يبني APK على خوادمه ويعطي رابط التنزيل.

## التخزين والإنترنت

المنتجات تُحفظ محليًا داخل الهاتف عبر AsyncStorage. القص وPDF يعملان محليًا. تحليل Gemini ورادار تيليجرام يحتاجان API/إنترنت، وسيتم ربطهما في مرحلة لاحقة عبر خادم آمن بدل وضع المفاتيح داخل APK.
