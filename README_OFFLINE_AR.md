# تشغيل Bo0 Factory محليًا Offline

## Windows

1. ثبت Python 3.10 أو أحدث من الموقع الرسمي، مع تفعيل خيار **Add Python to PATH**.
2. ضع ملفات المشروع كلها في مجلد واحد.
3. شغّل `run_offline.bat` بالنقر مرتين.
4. أول تشغيل فقط ينشئ بيئة `.venv` ويثبت المكتبات، لذلك يحتاج الإنترنت مرة واحدة.
5. بعد ذلك شغّل نفس الملف في كل مرة. لن ينفذ `pip install` مرة أخرى، وسيفتح التطبيق محليًا في المتصفح.

يمكنك أيضًا تشغيل `run_platform.bat`؛ أصبح يستخدم نفس المشغل الثابت ولا يعيد تنزيل المكتبات.

## Linux وmacOS

```bash
chmod +x run_offline.sh
./run_offline.sh
```

## ما يعمل بدون إنترنت

المونتاج المحلي، قص وعزل الصور، إضافة اللوجو، الكتالوج، تعديل المنتجات، تصدير CSV وPDF، والإعدادات المحلية تعمل بدون إنترنت بعد تثبيت المكتبات.

تحليل الصور عبر Gemini، رادار تيليجرام، هاشتاجات الترند، تنزيل فيديو من الروابط، وروابط المشاركة تحتاج اتصالًا بالإنترنت فقط عند الضغط على ميزتها. التطبيق نفسه لا يعيد تنزيل المكتبات عند التشغيل.

## البيانات

الكتالوج والإعدادات تحفظ محليًا في ملفات المشروع، ومنها `catalog.json` و`settings.json` و`catalog_images/`. خذ نسخة احتياطية من هذه الملفات عند نقل التطبيق إلى جهاز آخر.

## ملاحظة مهمة

هذا مشغل محلي داخل المتصفح، وليس ملف EXE واحدًا. لو أردت لاحقًا نسخة Windows EXE محمولة، يمكن بناء Installer منفصل على جهاز Windows بعد تثبيت النسخة الحالية.
